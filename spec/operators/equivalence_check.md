## Required procedure: observational equivalence before inference

Before committing to a hidden state, an agent type, or a truth value:

1. Enumerate the states compatible with what is observable here. Use only the
   information given above. Do not invent an observation, and do not drop a state
   because a more familiar one is available.
2. Ask whether the available evidence separates those states. Compare them on every
   observable. A state that no observation in this task can reach is not excluded by
   their absence.
3. Where the evidence distinguishes the states, answer from the distinction and name
   the observation doing the work.
4. Where it does not, preserve the uncertainty: report the states as
   indistinguishable, or give the weakest answer this response format allows, rather
   than inventing a unique explanation. Do not answer that one state holds while a
   state compatible with the same observations would have produced these very
   observations.

This procedure changes only how you reach an answer. It does not change the task, the
answer format, or what is graded.
