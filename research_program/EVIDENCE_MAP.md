# Capability-to-Evidence Map

| Capability claim | Observable evidence required | What does not suffice | Families |
|---|---|---|---|
| Solves the instance | Independently rebuilt ground truth and all required fields correct | Fluent justification or one correct action | all |
| Infers a latent mechanism | Correct mechanism on matched accurate/falsehood/omission/framing/error cases | Correct accept/verify/reject action alone | `epistemic_deception` |
| Reasons about incentives | Incentive attribution and action change across aligned/conflicted twins | Distrusting one named role | `epistemic_deception`, `epistemic_signaling` |
| Distinguishes deception from error | Error cases have uncertain speaker knowledge and differ from strategic falsehood under the same surface form | Calling all false statements lies | `epistemic_deception` |
| Predicts strategic adaptation | Correct audit-response counterfactual under a changed protocol | Static prediction of the initial message | `epistemic_deception`, future `reflexive_control` |
| Deploys strategic signaling | Correct signal and receiver-action prediction for private types and payoff regime | Detecting a deceptive speaker | `epistemic_signaling` |
| Handles nested beliefs | Exact public-announcement/nested-query result with relational restriction | Keyword matching or narrative plausibility | existing announcement/nested families |
| Discovers representation/invariant | Held-out presentation/rule/topology transfer plus preserved obligations and counterexample resistance | Success when the useful representation is supplied | weird-machine/category/recursive families |
| Generalizes | Held-out seeds, surface templates, rules, compositions, and interaction patterns | One seed or one endpoint-heavy archive score | all |
| Resists judge exploitation | Independent oracle/alternate judge agreement, malformed outputs rejected, visible-test overfits fail | Agreement with a shared oracle only | judge-integrity layer |
| Demonstrates a mechanism internally | Never established by these behavioral tasks alone; only compatible with observed external pattern | Explanation text or private chain-of-thought | all |

## Reporting unit

Report at least: field-level accuracy, exact-pass rate, calibration/confidence where requested, counterfactual consistency, shortcut-control delta, held-out generalization delta, seed variance, and judge/oracle disagreement. Keep source-backed conclusions, proposed hypotheses, and measured results in separate fields.
