# Sequential inquiry under a budget

`arena/epistemic_families/inquiry_control.mjs` implements a two-role finite sequential decision problem. A presenter first permutes the diagnostic menu. An investigator then buys queries and eventually chooses a world and gives the complete posterior. A latent world is drawn from a published integer-weight prior. Each query specifies a deterministic signal for every possible world. Histories, including erased signals, filter the prior. A uniform private ticket over the sum of the prior weights selects the hidden world. The trusted audit records that finite ticket count; neither the ticket nor the hidden world appears in the public view.

The independently adjustable axes are world count (4, 6, 8), query cost (1, 2, 3 out of six credits), presentation (full, pair-coarsened, zero-or-erasure), and partition topology (balanced, overlapping, nested). Presentation changes which worlds remain distinguishable. The topology changes the diagnostic partitions and hence the next useful query after an observation. These are resource and information changes, not descriptive labels. The family does not assert that every axis change makes every sampled instance harder.

The initial view has `role:"presenter"` and `phase:"presentation"`. Its only action is `{kind:"present",queryOrder:["q0","q1","q2","q3","q4","null"]}`, containing every query id exactly once. The presenter can change order only: facts, signals, costs, priors, and resource budgets remain fixed. The view then switches to `role:"investigator"` and `phase:"inquiry"`. Investigator actions are `{kind:"query",query:"q0"}` and `{kind:"answer",decision:"w0",forecast:["1/2",...]}`. A query can be bought once. The forecast must contain an exact nonnegative fraction for each world and sum to one. Invalid, repeated, unaffordable, wrong-role, or post-terminal actions throw without changing episode state.

The error cost is 12. At each belief state, the reference computes the exact Bellman value: stop with the best posterior decision, or pay for a query and take the posterior-weighted value of its continuations. It canonicalizes query ids before planning, so query-order permutations do not change its action or its tie breaks. Each investigator action accumulates its excess value over the optimum. The final decision contributes its stopping regret. The forecast contributes squared distance from the exact posterior. `score` and `investigatorScore` are `1/(1 + accumulated regret + forecast excess)`; all reported arithmetic is rational. Because regret is accumulated at each decision point, a fortunate branch cannot turn a poor inquiry policy into negative regret.

The presenter's objective is separately reported as `presenterRealizedObjective`: the investigator's query spend plus 12 if its final decision is wrong. This realized outcome is not a causal effect estimate. The scripted misleading presenter orders lower-information rows first, starting with the null query on the default setting. Its paired control uses the same hidden ticket and first-row investigator under neutral order. At seed zero/private ticket zero, neutral order costs the investigator one; the scripted order costs three. The test identifies an order effect only for that fixed paired policy and instance. Paired permutations leave the exact reference investigator's actions and outcomes unchanged. The `first_row` baseline uses a neutral presenter; `misleading_presenter` combines the scripted presenter with the same first-row investigator.

The constant-output query is a paid null control. Positive multiples of public seed 11 create a fully uninformative diagnostic family: an optimal investigator retains the prior and stops. Seed zero remains informative. On the default four-world setting at public seed 3, weights are `[1,1,2,3]`; immediate stopping costs `48/7`, while a full diagnostic costs `1`, giving immediate regret `41/7`. These are hand-derived checks separate from the planner. Tests also cover every prior ticket, all 81 axis combinations, the constrained role transition, state preservation, private-state separation, and snapshot isolation.

The bounded claim is constrained strategic presentation and exact finite query planning. Signal-coarsening axes change available information; the presenter's order-only action preserves it. This does not demonstrate open-ended inquiry, natural-language experiment design, or general persuasion effects beyond the tested fixed-policy paired comparisons.

Run `node --test tests/epistemic_families/inquiry_control.test.mjs` from the repository root.
