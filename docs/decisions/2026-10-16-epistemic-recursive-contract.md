# Epistemic family: local-to-global contract

Date: 2026-10-16.
Environment: `recursive_epistemic_gluing` only.
Phase 0 selection: highest B1 accuracy on UNSAT (bundle bit 1.000;
combined-task bit 0.429). Maze and distributed are not modified.

This note is developer-facing. Agent-facing prompts do not use the words
sheaf, presheaf, section, gluing, glue, holonomy, monodromy, cohomology,
Čech, local system, or fixed point.

## Formal model `[formal]`

A **nested situation** is a tuple
\((A, (F_\ell)_{\ell\in L}, \bar w, \varphi, \beta, \beta')\) where:

- \(A\) is a finite set of agents.
- \(L = (\ell_0,\dots,\ell_{d-1})\) is a finite list of frame names
  (outermost first). Frame \(F_\ell\) is a finite S5 model:
  worlds \(W_\ell\), atoms \(P_\ell: \mathrm{Prop}\to\mathcal P(W_\ell)\),
  and for each agent \(a\in A\) an equivalence relation \(\sim_a^\ell\)
  given as a partition of \(W_\ell\).
- \(\bar w = (w_0,\dots,w_{d-1})\) with \(w_i\in W_{\ell_i}\) is the
  **actual chain**.
- \(\varphi\) is a formula generated by
  \(\varphi ::= p \mid \lnot\varphi \mid \varphi\land\psi \mid K_a\varphi\).
- \(\beta\) (the outer **bundle**) is either absent or a map
  \(A\supseteq A_0\to W_{\ell_0}\).
- \(\beta'\) (the nested bundle) is either absent or a map
  \(A\supseteq A_1\to W_{\ell_1}\). It is ignored when \(d=1\).

A **global chain** is any \(c\in\prod_{\ell\in L} W_\ell\). Accessibility
for \(K_a\) is the product relation: \(c \sim_a c'\) iff
\(c_\ell \sim_a^\ell c'_\ell\) for every level \(\ell\).

An atom \(p\) holds at \(c\) iff there exists a level at which
\(c_\ell\in P_\ell(p)\). Nested modalities are evaluated by the usual
clause: \(K_a\varphi\) holds at \(c\) iff \(\varphi\) holds at every
\(c'\) with \(c\sim_a c'\). That is ordinary Kripke semantics on a
product, not public announcement or common knowledge.

## Sheaf-theoretic reading `[formal]`

Let \(X = W_{\ell_0}\) (outer worlds). Each agent \(a\) supplies a
cell \(U_a\subseteq X\), the \(\sim_a^{\ell_0}\)-class of \(\beta(a)\).
The **raw assignment sheaf** is the sheaf of functions on the discrete
space \(X\) (or, equivalently, the constant sheaf with stalk a singleton):
compatible local choices of a world glue uniquely, and every cover has
the sheaf property.

The **constrained presheaf** \(S\) of *admissible* local reports assigns
to a set of agents \(B\subseteq A\) the set of worlds lying in
\(\bigcap_{a\in B} U_a\) (and, when \(\beta'\) is present, the analogous
intersection on the inner frame). Restriction is intersection with a
smaller set of agents.

- Compatible local reports on a cover \(\{U_a\}\) **do** glue as raw
  assignments: that is the sheaf axiom for the raw structure, and it
  holds.
- \(S(A)\) may still be empty: there is no world in every cell. That is
  **absence of a global section of \(S\)**, not a failure of the sheaf
  axiom.
- When \(|A|=2\), \(S(A)=\emptyset\) iff the pairwise intersection is
  empty. Phase 0 measured exactly this: B1 UNSAT accuracy 1.0.
- When \(|A|\ge 4\), every pairwise and every triple intersection of
  cells may be nonempty while \(\bigcap_{a\in A} U_a=\emptyset\).
  That is the NEG-deep class. It is Čech-nerve data of a finite cover
  of a four-point set, not a cohomology theory of an interesting space.
- Nested \(\beta'\) is a second constrained presheaf on \(W_{\ell_1}\).
  Flattening (dropping inner frames and \(\beta'\)) can make \(S\) look
  nonempty while the product constraint is empty. That is NEG-recursive.

This family **does not** claim a nontrivial \(H^1\) invariant beyond
“the nerve of the reported cells fails to witness a common world”.
It is a finite constraint-presheaf view of information cells plus
ordinary modal evaluation. `[formal]`

## Operational semantics `[formal]`

1. Evaluate \(\varphi\) at \(\bar w\) by the product-Kripke clauses,
   with a hard step budget of \(50\,000\) connective/world visits.
   Exhausting the budget raises `OracleBudgetExceeded` and is **not**
   unsat.
2. If \(\beta\) is present, compute the outer cells and their
   intersection. If \(\beta'\) is present and \(d\ge 2\), compute the
   inner cells and their intersection. The bundle is possible iff every
   present level has a nonempty intersection. A reported world that is
   not in the frame, or not in any block of that agent, yields an empty
   **local** cell.
3. **Task SAT** iff \(\varphi\) holds at \(\bar w\) and every present
   bundle is possible. TREE instances with no bundle are SAT iff the
   query holds.

## Exact verifier `[formal]` `[tested]` (tests added this pass)

The judge does not call `reference_certificate` or `arm_reference`.

- `query_value` is recomputed by `eval_formula` on the given model.
- On depth-1 models the same Boolean is cross-checked against
  `flatten_model` (explicit global worlds = the single frame).
- If the candidate claims `bundle_possible=true`, it must exhibit
  `joint_world` (and `joint_inner` when \(\beta'\) is present). The
  judge checks membership in every cell. That is a SAT witness, not a
  Boolean comparison with the reference solver.
- If the candidate claims `bundle_possible=false`, the judge enumerates
  the finite intersections itself. Empty intersection is UNSAT;
  nonempty intersection rejects the claim. Exhausted modal budget is
  `judge_runtime_error`.

Resource contract: modal evaluation is bounded by the step counter;
bundle checks are \(O(|A|\cdot|W|)\) set intersections. No wall-clock
assertions.

## Why recursion and global interaction matter `[tested]` after generators

| Class | Local cells | Pairwise | Triple | Global \(S(A)\) | Flattening |
|---|---|---|---|---|---|
| POS-plain | nonempty | nonempty | nonempty | nonempty | same SAT |
| POS-recursive | n/a (no bundle) | n/a | n/a | query true via inner atom | query false |
| NEG-local | some empty | — | — | empty | UNSAT (trivial) |
| NEG-pairwise | nonempty | some empty | — | empty | UNSAT |
| NEG-deep | nonempty | nonempty | nonempty | empty | UNSAT (no nesting needed) |
| NEG-recursive | nonempty | nonempty (outer) | — | empty because of \(\beta'\) | **SAT** (inner dropped) |

POS-recursive uses query \(q\) which lives only on an inner frame.
Flattening drops that frame, so the atom is absent. That is ordinary
nested model checking, recorded honestly as such, not as a cohomological
obstruction.

## Unsupported / out of scope

- Common knowledge, public announcements, dynamic epistemic logic.
- World-dependent inner frames (the product model is not a bundle of
  pointed models indexed by outer worlds).
- Maze and distributed families (Phase 0 non-selected).
- Model-level latent-structure discovery. `[requires model runs — not done]`
