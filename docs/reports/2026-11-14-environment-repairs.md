# Environment repairs and family campaign validation

This work continues the three requested tracks: develop interactive epistemic
families with explicit axes, execute their GitHub workflows, and repair the
confirmed defects in the November 11 environment audit. The nine new families
were already published at `c3c33f1fd95ba8577ce7bb0721388c401deca670`.

Implementation and validation are in progress on
`codex/environment-audit-repairs-20261114`. Historical campaigns and audit
artifacts are retained unchanged. No `core.py` file is in the edit scope.

## Repair scope

| Area | Work |
|---|---|
| Original category environments | Declared operators/fairness, answer cues, effective axes, numerical judges, and mathematical claim boundaries. |
| ML and recurrent environments | BatchNorm behavior acceptance, MoCo temperature/key law, RoPE rotations/offsets and public reference leakage, fixed repair cues, reproducible dependencies. |
| Trajectory environments | Payload encoding, format invariance, and held-out presentation coverage. |
| Unusual computational substrates | Importable visible tests, precise substrate grammars, whitespace, and graph ordering controls. |
| Legacy epistemic environments | Identifiable evidence, explicit knowledge/counterfactual semantics, policy-reading scope, and accurate instructions. |
| New interactive families | Full pairwise reference/replay coverage, separate family metrics, complete documentation, and hosted controls. |
